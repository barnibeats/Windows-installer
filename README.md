# Windows Installer

Приложение для установки Windows 10/11 из ISO / WIM / ESD на выбранный диск (**GPT/UEFI** и **MBR/BIOS**) и для снятия образа настроенной Windows (Sysprep + DISM). Работает в обычной Windows и в **WinPE**. Тёмная и светлая темы, русский, английский и украинский языки.

> English: installs Windows from ISO/WIM/ESD onto a chosen disk (GPT/UEFI or MBR/BIOS) and captures a prepared Windows into a WIM. Runs in Windows and in WinPE. Self-updates from this repository's releases.

## Возможности

**Установка**
- ISO, WIM и ESD: выбор файла, поиск ISO на всех дисках (кроме системного), выбор редакции.
- ISO монтируется напрямую через `virtdisk` (работает и без модулей PowerShell, например в WinPE); запасные пути: `Mount-DiskImage`, распаковка `install.wim` через 7-Zip.
- Выбор диска из таблицы (модель, размер, шина, GPT/MBR, тома). **Системный диск и диск с образом/программой выбрать нельзя.**
- GPT + UEFI или MBR + BIOS; раздел WinRE; **свой размер раздела Windows** (или весь диск) и раздел `Data` из остатка; драйверы в систему.
- Подтверждение стирания вводом номера диска.
- Временные файлы DISM пишутся на целевой раздел, а не в RAM-диск WinPE.

**Захват**
- В Windows: проверка (BitLocker, домен, Store-приложения, программы вне диска C:, ярлыки), страховка ярлыков, файл ответов `unattend.xml` (пропуск создания новой учётки), Sysprep `/generalize /oobe /shutdown`, повтор с удалением мешающих Store-приложений.
- В WinPE: выбор Windows, статус Sysprep, снятие WIM через DISM на внешний диск.
- `capture.cmd` для стандартного установщика Windows (без .NET).

**Обновления**
- Новая версия скачивается из релизов этого репозитория, проверяется (размер, SHA-256, версия, подпись при наличии) и ставится при закрытии программы.

## Скачать и запустить

Берите `WindowsInstaller.exe` из [последнего релиза](https://github.com/barnibeats/Windows-installer/releases/latest). Установка не нужна; программа запрашивает права администратора. Требуется .NET Framework 4.x (есть в Windows 10/11 и в большинстве сборок WinPE).

В WinPE: положите exe на внешний диск и запустите.

## Сборка

Нужен только компилятор C#, встроенный в Windows (.NET Framework 4.x, C# 5), и PowerShell:

```powershell
.\build.ps1            # WindowsInstaller.exe, версия = последний тег + "-dev"
.\build.ps1 -Test      # то же + самопроверка
```

Самопроверка (`WindowsInstaller.exe --selftest отчёт.txt`) ничего не меняет в системе: проверяет скрипты разметки, разбор вывода DISM, переводы, список дисков.

Служебные режимы (для разработки):

| Ключ | Что делает |
| --- | --- |
| `--selftest <файл>` | отчёт самопроверки; `--iso <файл>` дополнительно открывает образ (ISO монтируется только для чтения) |
| `--shots <папка>` | сохраняет скриншоты всех вкладок в обеих темах |
| `--e2e <лог> <диск> <образ> <индекс> <gpt\|mbr> [ГБ]` | **реальная** установка, но только на виртуальный диск (VHD/VHDX); любой другой диск программа отказывается трогать |

## Выпуск новой версии

```powershell
git tag v1.0.0
git push origin v1.0.0
```

GitHub Actions соберёт exe, прогонит самопроверку и опубликует релиз с `WindowsInstaller.exe` и `latest.json`. Установленные копии найдут новую версию сами. Сборки из ветки (без тега) помечаются `-dev` и не обновляются.

## Структура

| Путь | Что внутри |
| --- | --- |
| `src/` | исходники (C# 5, WinForms без внешних зависимостей) |
| `src/Installer.cs`, `Images.cs`, `Disks.cs` | установка: разметка, образы, диски |
| `src/Capture.cs` | захват: проверки, Sysprep, DISM |
| `src/Updater.cs` | самообновление |
| `src/Theme.cs`, `Controls.cs`, `*Page.cs` | оформление (темы, элементы управления) |
| `src/Strings.cs` | переводы (ru/en/uk) |
| `build.ps1` | сборка (иконка, версия, компиляция) |
| `.github/workflows/release.yml` | CI и выпуск релизов |

## Безопасность

Установка **полностью стирает** выбранный диск. Перед запуском проверьте номер и размер диска. Захват через Sysprep делает систему «обобщённой»: не включайте её с собственного диска до снятия образа. Подробности и ограничения Sysprep (активация, Store-приложения, профили) показаны в самой программе на вкладке «Захват».
